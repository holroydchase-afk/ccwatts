# Code of Conduct

ccwatts adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), as its code of conduct for everyone who takes part: in issues, pull requests, discussions and any other project space.

In short: be welcoming, be respectful, assume good faith, and accept that people disagree. Harassment, personal attacks and publishing others' private information are not acceptable.

## Reporting

If someone's behavior breaks this code, tell the maintainer privately through GitHub:

- For anything sensitive, use the repository's **Security** tab > **Report a vulnerability**, which opens a private thread with the maintainer only (mark the title "Conduct report").
- Otherwise, contact the maintainer through their GitHub profile.

Reports are kept confidential. The maintainer will review each one and respond as the Contributor Covenant's enforcement guidelines describe, from a private warning up to a ban from the project.
