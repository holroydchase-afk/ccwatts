      Try it on your own logs

      Claude Code saves logs in ~/.claude/projects. Pick that folder, or drop any .jsonl files here. Files are read by this page on your device and never uploaded. On a Mac the folder is hidden: in the picker, press ⌘ ⇧ . to show it.

      Make a counts-only copy of my Claude Code usage for ccwatts.

Read every .jsonl file under ~/.claude/projects. For each line whose "type" is "assistant" and that has message.usage, write one JSON line containing only:
- type, timestamp, requestId
- cwd, reduced to the last folder name (never the full path)
- message.id and message.model
- message.usage with input_tokens, cache_creation_input_tokens, cache_read_input_tokens and output_tokens

Leave out everything else, especially message content. Save the lines as ccwatts-usage.jsonl and give me the file to download. If you can't offer a download, print the lines in one code block instead.
